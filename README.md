# Aidan Hughes — Selected Frames

## Open the site
Unzip this package, keep all files and the assets folder together, and open index.html in your browser. The commercial plays on its own project page. No installation is required.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, aidan-portfolio).
2. Choose Add file → Upload files. Upload the contents of this ZIP directly to the repository root, including the assets folder. Do not upload the ZIP itself or an extra enclosing folder.
3. Commit the files.
4. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. When GitHub shows your published URL, open it and verify the video, images, email, and LinkedIn links. Use that working URL for Canvas, or submit screenshots if publishing is unfinished.

## Files
- index.html — homepage, Work, About, Contact
- chalk-commercial.html — video, contributions, reflection
- styles.css — forest palette and responsive layout
- assets/ — all photos, three real video frames, optimized video, favicon
- .nojekyll — static hosting marker

## Updating
The source is beginner-editable HTML and CSS. Portfolio copy is based on Aidan’s supplied wording, with grammar and spelling corrected at his request. Update copy directly in the relevant HTML file; homepage project context also appears on the project page. There are no fake projects, invented testimonials, or business claims.

The video is an optimized 720 × 1280 copy of the original 30-second upload. It has native controls and does not autoplay. If the commercial contains meaningful spoken content or meaningful sound cues, add an accurate WebVTT captions file using a <track kind="captions" src="assets/captions.vtt" srclang="en" label="English"> element inside <video>. A transcript or descriptive version can be added alongside the project notes.

## Checkpoint
The homepage shows your name, professional headshot, career target, brand statement, three visible content areas, and a real work sample with context. Write your own 2–3 sentence completion plan, including when you will finish, in the Canvas comment box. It is intentionally absent from the public portfolio.

Business work and personal Instagram are intentionally omitted for now. Add more projects only when you have the actual media and your own role/context to include.
